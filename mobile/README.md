# TooruDragon Mobile

Мобильное приложение будет единым клиентом ко всем ядрам через Main Core / API Gateway.

## Alpha contract

- Main Core base URL: configurable
- Local development default: http://127.0.0.1:8700
- Health: GET /health
- Core state: GET /cores

## Planned targets

- Android
- iOS

На следующем этапе будет выбран клиентский стек и добавлена авторизация, discovery локального сервера и безопасное удалённое подключение.
