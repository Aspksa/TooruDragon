# TooruDragon Launcher

## Фирменные ресурсы

- `logo.svg` — основной знак TooruDragon.
- `tooru-maid.png` — основной аниме-арт главной страницы.

GUI автоматически загружает `tooru-maid.png`, если файл присутствует. Без него лаунчер остаётся рабочим.

## Windows-интеграция

В разделе **Настройки** доступны автозапуск Windows через Task Scheduler, отключение автозапуска и создание ярлыка.

## System tray

При сворачивании или закрытии окна лаунчер остаётся в трее. Меню: открыть, запустить всё, перезапустить, остановить всё, Web UI, выход.

## Уведомления

Windows-уведомления показываются при готовности всех ядер, сворачивании в tray, изменении автозапуска и создании ярлыка.
