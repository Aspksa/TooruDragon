# Оформление TooruDragon Launcher

Основной арт лаунчера должен лежать здесь:

`assets/launcher/tooru-maid.png`

Рекомендуется PNG 1920×1080 или выше, тёмная фиолетово-синяя палитра и взрослая аниме-драконица-горничная.

GUI остаётся работоспособным даже без изображения. Это позволяет запускать систему с любого носителя, а оформление менять независимо от логики лаунчера.
