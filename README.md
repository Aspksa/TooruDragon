# TooruDragon v0.1.0 Alpha

Дата старта: **29 сентября 2026**

TooruDragon — модульная AI-система с главным управляющим ядром и специализированными ядрами.

## Ядра

- **Главное ядро** — `127.0.0.1:8700`
- **Ядро Tooru/AI** — `127.0.0.1:8701`
- **Лаборатория Tooru/AI** — `127.0.0.1:8702`
- **Домашнее ядро** — `127.0.0.1:8703`
- **Рабочее ядро** — `127.0.0.1:8704`
- **Мобильное ядро** — `127.0.0.1:8705`

## Назначение

### Главное ядро
- запуск и контроль сервисов;
- маршрутизация;
- health-check;
- общая конфигурация;
- единая точка управления.

### Tooru/AI
- диалог;
- AI runtime;
- контекст;
- память;
- инструменты;
- маршрутизация AI-задач.

### Лаборатория Tooru/AI
- эксперименты;
- разработка;
- генерация и редактирование кода;
- тестирование;
- сборка;
- инструменты разработчика.

### Дом
- бытовые сценарии;
- локальная автоматизация;
- персональные задачи.

### Работа
- проекты;
- документы;
- задачи;
- рабочие интеграции.

### Мобильное ядро
- шлюз для мобильных клиентов;
- синхронизация устройств;
- координация мобильных сессий;
- будущий слой push-уведомлений;
- связь мобильного приложения с остальными ядрами.

## Общие компоненты

- `StartTooruDragon.bat` — единый запуск системы на Windows;
- Auto Update — обновление из GitHub перед запуском;
- Web UI — `127.0.0.1:8710`;
- SQLite — локальная база Alpha;
- Main Core — единая точка контроля состояния всех ядер.
