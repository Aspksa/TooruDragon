# TooruDragon v0.1.0 Alpha

Дата старта: **29 сентября 2026**

TooruDragon — модульная AI-система с главным управляющим ядром и специализированными ядрами.

## Архитектура

### Main Core
Главное управляющее ядро:
- запуск и остановка всех компонентов;
- маршрутизация запросов между ядрами;
- общая конфигурация;
- контроль обновлений;
- единая API-точка для Web и Mobile;
- доступ к общим базам данных.

### Tooru/AI Core
Основное AI-ядро Тору:
- диалог;
- контекст;
- работа с моделями;
- память и инструменты;
- маршрутизация AI-задач.

### Workshop Core
Мастерская Tooru/AI:
- разработка;
- генерация и редактирование кода;
- тестирование;
- сборка;
- эксперименты и инструменты разработчика.

### Home Core
Домашнее ядро:
- бытовые сценарии;
- локальная автоматизация;
- персональные задачи;
- интеграции домашней среды.

### Work Core
Рабочее ядро:
- рабочие процессы;
- проекты;
- документы;
- задачи;
- интеграции рабочих сервисов.

## Общие компоненты

- `StartTooruDragon.bat` — единый запуск системы на Windows.
- Auto Update — обновление из GitHub перед запуском.
- Web — браузерный интерфейс.
- Mobile — мобильное приложение как общий клиент ко всем ядрам.
- Databases — общие и специализированные базы данных.
- API Gateway — единая точка доступа клиентов к ядрам.
