# Архитектура TooruDragon — v0.1.0 Alpha

## Общая схема

```text
                 Web UI
                   |
             Главное ядро
             127.0.0.1:8700
      _____________|________________
     |        |         |      |     |
 Tooru/AI  Лаборатория Дом   Работа Mobile
   8701       8702      8703   8704  8705
     |        |         |      |     |
     +--------+---------+------+-----+
                   |
               Data Layer
```

## Ядра

### Главное ядро — 8700
Оркестрация, маршрутизация, диагностика и единое управление системой.

### Tooru/AI — 8701
Основной AI runtime Тору: диалог, память, модели, контекст и инструменты.

### Лаборатория Tooru/AI — 8702
Эксперименты, разработка, код, тестирование, сборка и инженерные инструменты.

### Дом — 8703
Домашние сценарии, локальная автоматизация и персональные задачи.

### Работа — 8704
Рабочие проекты, документы, задачи, отчёты и интеграции.

### Мобильное ядро — 8705
Отдельный сервис мобильного слоя:
- мобильный API-шлюз;
- синхронизация устройств;
- управление мобильными сессиями;
- будущие push-уведомления;
- связь Android/iOS-клиентов с системой.

## Web

Web UI работает отдельно на `127.0.0.1:8710`.

## Данные

Для Alpha используется SQLite. Далее архитектура предусматривает отдельные системные и тематические хранилища и переход серверной версии на PostgreSQL.

## Запуск

`StartTooruDragon.bat`:
1. проверяет Git;
2. проверяет Python;
3. обновляет репозиторий;
4. инициализирует базу;
5. запускает специализированные ядра;
6. запускает Главное ядро;
7. запускает Web UI;
8. проверяет состояние всех ядер.
